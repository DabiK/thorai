# Maquettes de la vue jeu (direction Aube)

Copies locales des 13 écrans de la page 3 du canvas Design (https://claude.ai/artifact/M6dsMX8171h3WhpyDvq6Zh). Chaque fichier s'ouvre dans un navigateur. Le haut d'une planche fait 1920 × 1080 (écran du haut de la Thor), le bas 1240 × 1080 (écran du bas).

Les styles viennent de `../outils/thorai-pixel.css`, thème `.t-aube`. Les images viennent de `../assets/aube/`. Ce sont des références visuelles : le code de l'app reconstruit ces écrans dans `android/game/ui`.
